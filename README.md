# CampusConnect 360

CampusConnect 360 is a Smart Campus Utility & Student Support Platform built as a MERN stack college project.

## Tech Stack

- MongoDB
- Express.js
- React.js
- Node.js

## Main Modules Planned

- Login/Register
- Student Dashboard
- Admin Dashboard
- Department Dashboard
- Complaint Management
- Notices
- Events
- Lost & Found
- AI Chatbot
